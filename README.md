# yres.reminder2

Aplikasi pengingat web sederhana yang ringan dan responsif untuk membantu mengelola jadwal serta catatan pengingat harian.

## 🚀 Fitur Utama
- **Tampilan Antarmuka Bersih:** Menggunakan desain UI modern dengan aset logo terintegrasi.
- **Berjalan Langsung di Browser:** Dibuat menggunakan HTML, CSS, dan JavaScript tanpa perlu instalasi rumit.
- **Ringan & Cepat:** Bebas dari dependensi berat sehingga dapat dimuat secara instan.

## 📁 Struktur File
- `index.html` — Halaman utama aplikasi pengingat.
- `logo.png` / `logo-clean.png` / `logo-icon.png` — Aset gambar dan identitas visual aplikasi.
