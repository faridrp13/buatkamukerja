Apa itu YRES?

YURA Reminder System (YRES) adalah alat bantu pengiriman pesan pengingat tagihan kepada pelanggan secara massal via WhatsApp dan Google Messages (SMS/RCS), langsung dari browser Anda.

Langkah Penggunaan

1

Unduh Template Excel

Klik tombol Unduh Template di navbar untuk mendapatkan format kolom yang benar: No_Kartu, Nama, No_HP, Nominal.

2

Isi Data & Unggah

Isi data tagihan pelanggan di Excel, lalu seret file ke area unggah atau klik untuk memilih file. Data akan langsung muncul di tabel.

3

Atur Template Pesan

Edit teks template di panel kanan menggunakan variabel {nama}, {noKartu}, {nominal}.

4

Kirim Pesan

Pilih platform pengiriman (WhatsApp atau Google Messages) dan mode (App atau Web), lalu klik tombol kirim di setiap baris pelanggan. Setelah dikirim, tandai statusnya sebagai Selesai.

Tips

Data Anda tersimpan otomatis di browser. Gunakan tombol Data Contoh untuk melihat demo tanpa harus upload file terlebih dahulu.

Google Messages

Kirim SMS & RCS langsung dari browser laptop Anda dengan cara menghubungkan HP Android ke Google Messages Web. Tersedia mode App (via tautan sms:) dan Web (messages.google.com/web).

Mode App

Membuka aplikasi SMS bawaan HP atau Phone Link (Windows). Cocok jika HP terhubung langsung ke PC.

Mode Web

Membuka Google Messages Web di browser. HP harus sudah dipasangkan (pairing) terlebih dahulu.

Cara Pairing Google Messages Web

1

Buka Google Messages di HP

Pastikan aplikasi Pesan (Google Messages) sudah terpasang di HP Android Anda. Ini adalah aplikasi pesan bawaan di sebagian besar perangkat Android.

2

Masuk ke Menu Pairing

Ketuk foto profil atau ikon tiga titik (⋮) di pojok kanan atas, kemudian pilih Penyambungan Perangkat (Device Pairing).

3

Scan QR Code di Laptop

Buka messages.google.com/web di browser laptop, lalu pindai QR code yang muncul menggunakan kamera HP Anda.

Siap Digunakan!

Semua SMS & RCS kini bisa dikirim langsung dari laptop Anda melalui YRES. Pilih mode Web pada selector Google Messages di tabel.

Catatan: Koneksi pairing membutuhkan HP dan laptop terhubung ke internet. Centang opsi "Ingat perangkat ini" agar tidak perlu scan QR setiap saat.

WhatsApp

Kirim pesan WhatsApp ke pelanggan langsung dari YRES. Tersedia mode App (membuka aplikasi WA di HP/Desktop) dan Web (membuka WhatsApp Web di browser).

Mode App

Membuka aplikasi WhatsApp di HP atau WhatsApp Desktop. Menggunakan skema wa.me/.

Mode Web

Membuka web.whatsapp.com di browser. HP harus sudah dipasangkan dengan WhatsApp Web.

Cara Pairing WhatsApp App (Desktop)

1

Instal WhatsApp Desktop

Unduh dan instal WhatsApp Desktop dari situs resmi untuk Windows atau Mac. Atau gunakan mode App langsung ke HP.

2

Buka Menu Perangkat Tertaut

Di HP, buka WhatsApp → ketuk Tiga Titik (⋮) → pilih Perangkat Tertaut (Linked Devices) → ketuk Tautkan Perangkat.

3

Scan QR Code

Arahkan kamera HP ke QR code yang muncul di WhatsApp Desktop atau di browser (web.whatsapp.com) hingga otomatis terhubung.

Cara Menggunakan WhatsApp Web

1

Buka WhatsApp Web

Buka web.whatsapp.com di browser laptop (Chrome / Edge / Firefox).

2

Pindai QR Code

Di HP: buka WhatsApp → Perangkat Tertaut → Tautkan Perangkat → pindai QR code yang tampil di browser laptop.

Siap Digunakan!

Pilih mode Web pada selector WhatsApp di YRES, lalu klik tombol kirim — pesan akan langsung terbuka di WhatsApp Web.

Tips: Biarkan tab WhatsApp Web tetap terbuka di background agar tombol kirim dari YRES langsung bekerja tanpa perlu login ulang.
