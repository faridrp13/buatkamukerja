Apa itu YRES?

YURA Reminder System (YRES) adalah alat bantu pengiriman pesan pengingat tagihan kepada pelanggan secara massal via WhatsApp dan Google Messages (SMS/RCS), langsung dari browser Anda.

Langkah Penggunaan

1

Unduh Template Excel

Klik tombol Unduh Template di navbar untuk mendapatkan format kolom yang benar: No_Kartu, Nama, No_HP, Nominal.

2

Isi Data & Unggah

Isi data tagihan pelanggan di Excel, lalu seret file ke area unggah atau klik untuk memilih file. Data akan langsung muncul di tabel.

3

Atur & Pilih Template Pesan (Sistem ON/OFF)

Pilih Format 1 (Tunggakan), Format 2 (REHAB), atau Format 3 (VA & Kanal). Variabel otomatis: {nama}, {no kartu}, {nominal}, {date today}, {month year today}, {no kartu.slice 2}.

4

Kirim Pesan

Pilih platform pengiriman (WhatsApp atau Google Messages) dan mode (App atau Web), lalu klik tombol kirim di setiap baris pelanggan. Setelah dikirim, tandai statusnya sebagai Selesai.

Tips

Data Anda tersimpan aman di database SQLite server. Gunakan tombol Data Contoh untuk melihat demo tanpa harus upload file terlebih dahulu.

Google Messages

Kirim SMS & RCS langsung dari browser laptop Anda dengan cara menghubungkan HP Android ke Google Messages Web. Tersedia mode App (via tautan sms:) dan Web (messages.google.com/web).

Mode App

Membuka aplikasi SMS bawaan HP atau Phone Link (Windows). Cocok jika HP terhubung langsung ke PC.

Mode Web

Membuka Google Messages Web di browser. HP harus sudah dipasangkan (pairing) terlebih dahulu.

Cara Pairing Google Messages Web

1

Buka Google Messages di HP

Pastikan aplikasi Pesan (Google Messages) sudah terpasang di HP Android Anda.

2

Masuk ke Menu Pairing

Ketuk foto profil atau ikon tiga titik (⋮) di pojok kanan atas, kemudian pilih Penyambungan Perangkat (Device Pairing).

3

Scan QR Code di Laptop

Buka messages.google.com/web di browser laptop, lalu pindai QR code yang muncul menggunakan kamera HP Anda.

WhatsApp

Kirim pesan WhatsApp ke pelanggan langsung dari YRES. Tersedia mode App dan Web.

Mode App

Membuka aplikasi WhatsApp di HP atau WhatsApp Desktop via skema wa.me.

Mode Web

Membuka web.whatsapp.com di browser.
